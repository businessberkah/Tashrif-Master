نبذة عن قطرب

قُطْرُب محرّك متكامل لتصريف الأفعال العربية، يدعم أكثر من ٢٢ ألف فعل (ثلاثية، رباعية، مزيدة) بكل أزمنتها الاثني عشر وصيغ البناء للمعلوم والمجهول والأمر. يمكن استخدامه عبر الموقع أو عبر واجهة API مفتوحة.

المصدر مفتوح على GitHub بموجب رخصة GPL. أُنتج بدعم مجموعة عربايز.

واجهة API

GET — تصريف فعل

GET /api?verb=<فعل>&haraka=<حركة>&trans=<0|1>

أو بديلاً عبر المسار: /api/<verb>/<haraka>

المعامل القيم المقبولة الوصف
verb فعل عربي مشكّل أو غير مشكّل الفعل المراد تصريفه
haraka a · u · i · فتحة · ضمة · كسرة حركة فاء المضارع (افتراضي: فتحة)
trans 0 · 1 0 = لازم، 1 = متعدٍّ (افتراضي: 1)

مثال:

curl "https://qutrub.arabeyes.org/api?verb=كتب&haraka=u&trans=1"

مثال على الاستجابة (مقتطف):

{
  "result": {
    "0": {"0": "الضمير", "1": "الماضي", "2": "المضارع المرفوع", ...},
    "1": {"0": "هو",     "1": "كَتَبَ",  "2": "يَكْتُبُ",       ...},
    ...
  },
  "verb_info": "الفعل كَتَبَ - يَكْتُبُ فعل ثلاثي متعدي سالم",
  "suggest": []
}

POST — تصريف مع خيارات متقدمة

POST /ajaxGet

يقبل JSON بالشكل:

{
  "data": {
    "action":       "Conjugate",

  }

أمثلة للمطوّرين

Python:

import requests
r = requests.get("https://qutrub.arabeyes.org/api",
                 params={"verb": "كتب", "haraka": "u", "trans": 1})
data = r.json()
print(data["verb_info"])

JavaScript (Fetch):

const res  = await fetch('/api?verb=كتب&haraka=u&trans=1');
const data = await res.json();
console.log(data.verb_info);
